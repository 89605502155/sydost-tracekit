# Границы и теория

## Оценка по отсчётам

Пусть `a` — выделение (известно точно из журнала хоста), `d` — потребность. Дефицит
`f = (d − a)⁺`, `D = ∫ f dt`. Отсчёты `d` с шагом `ℓ`, удержанные до следующего отсчёта, задают
простую функцию `d_ℓ`. Оценка равна

    D_ℓ = ∫ (d_ℓ − a)⁺ dt.

При `ℓ → 0` имеем `d_ℓ → d` почти всюду, и по теореме Лебега о мажорированной сходимости
`D_ℓ → D` (подынтегральные функции ограничены максимумом памяти плюс резерв).

## Утверждение 4.1: удержание

    |D_ℓ − D| ≤ ℓ · V(d),

где `V(d)` — полная вариация потребности. Следует из `|x⁺ − y⁺| ≤ |x − y|`. Граница верна и
имеет первый порядок по `ℓ`, но считает вариацию во все моменты времени.

```python
import numpy as np
from sydost_tracekit import hold_error_bound

print(hold_error_bound(np.array([[0.0, 2.0, 1.0]]), 0.5))
```

## Уточнённая граница для удержания

Пусть `x_k` — удержанное значение в точке мелкой сетки `k`. Погрешность точки отлична от нуля,
только если потребность или удержанное значение выше выделения. Поточечно

    −(d_k − max(x_k, a_k))⁺  ≤  (оценка − точное значение в k)  ≤  (x_k − max(d_k, a_k))⁺,

и суммирование по мелкой сетке с шагом `dt` даёт

    −dt Σ (d_k − max(x_k, a_k))⁺  ≤  D_ℓ − D  ≤  dt Σ (x_k − max(d_k, a_k))⁺.

Нижняя граница считает только подъёмы потребности над выделением, верхняя — только спады
удерживаемого значения над ним. Она никогда не шире `ℓ·V(d)` и заметно уже, когда потребность
держится ниже выделения.

```python
from sydost_tracekit import hold_error_bounds_refined, simulate, synthetic_trace

tr = synthetic_trace("A", T=600.0, dt=0.1, seed=7)
alloc = simulate(tr, interval_s=4.0).alloc
lo, hi = hold_error_bounds_refined(tr.d, alloc, tr.dt, ell=4.0)
print(f"уточнённая: [{lo:.1f}, {hi:.1f}] MiB*s")
```

## Утверждение 4.2: линейная интерполяция

Если `d` `L`-липшицева, имеет `K` изломов и `|d''| ≤ M` вне изломов, то

    |D_lin − D| ≤ ℓ² · (T·M/12 + K·L/3).

На гладком шаге погрешность интерполяции не больше `M·u·(ℓ − u)/2` (`u` — время от начала шага),
её интеграл равен `M·ℓ³/12`. На шаге с изломом погрешность не больше `2L·u·(ℓ − u)/ℓ`, интеграл
`L·ℓ²/3`. Суммирование по шагам даёт утверждение. Ссылка для доказательства — стандартная оценка
погрешности линейной интерполяции. Константы оценивает `estimate_constants` по эталонной трассе;
для зашумлённой трассы `M` и `K` велики, и граница груба.

## Точный интеграл положительной части

На каждом отрезке кусочно-линейного сигнала `g = x − a` линейна. Интеграл её положительной части
берётся по точке пересечения с нулём, поэтому интеграл `(x − a)⁺` точен:

```python
import numpy as np
from sydost_tracekit import positive_part_integral

t = np.array([0.0, 1.0, 2.0])
x = np.array([0.0, 4.0, 0.0])
a = np.array([2.0, 2.0, 2.0])
print(positive_part_integral(t, x, a))
```

## Какая частота опроса нужна?

Для допустимой абсолютной погрешности `E` (МиБ·с) допустимый шаг — наибольшее `ℓ`, при котором
граница метода не превышает `E`: `ℓ = E / V` для удержания и `ℓ = sqrt(E / C)` для линейной
интерполяции, где `C = Σ (T·M/12 + K·L/3)` по машинам. `plan_sampling` выбирает метод с большим
шагом, то есть с меньшей частотой.

```python
from sydost_tracekit import estimate_constants, plan_sampling, synthetic_trace

tr = synthetic_trace("B", T=600.0, dt=0.1, seed=7)
plan = plan_sampling(1e4, estimate_constants(tr.d, tr.dt))
print(plan.method, round(plan.step_s, 3), round(plan.rate_hz, 3))
```

## Область применения

Границы относятся к восстановлению потребности. Они считают выделение известным точно и баллон
мгновенным. Синтетические трассы нужны для отладки; выводы исследования должны опираться на
трассы реальной системы.
