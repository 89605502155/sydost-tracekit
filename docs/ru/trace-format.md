# Формат трасс

Трасса — потребность `d[i, k]` виртуальной машины `i` в момент `k·dt`, в МиБ. Время — в секундах.
Потребность ВМ берётся из гостя:

    d = (MemTotal − MemAvailable) / 1024 + резерв            [МиБ]

## Файл CSV

Заголовок: `t_s,<имя1>,<имя2>,...`, по одной строке на точку сетки:

```text
t_s,vm1,vm2
0.000000,1024.000,2048.500
0.100000,1024.300,2048.500
```

- Первый столбец — `t_s`, сетка равномерна: соседние моменты отличаются на `dt` с точностью
  округления (допуск — больше из 1e-6 с и 1e-3·dt).
- Значения — конечные числа; пустые значения и NaN отвергаются.
- Имена уникальны и не содержат запятых.
- `<файл>.json` (необязательный) хранит метаданные: `dt`, `names` и дополнительные поля
  (сценарий, зерно, метод, источник). Его пишет `save_trace` и читает `load_trace`.

```python
from sydost_tracekit import Trace, load_trace, save_trace

tr = Trace(0.5, [[1.0, 2.0, 3.0]], ["vm1"])
save_trace(tr, "trace.csv")
print(load_trace("trace.csv").names)
```

## Записи регистратора

Гостевой регистратор пишет по одному CSV на ВМ со столбцами `t_mono_s`, `t_real_s`,
`mem_total_kib`, `mem_free_kib`, `mem_available_kib`, `cached_kib`, `swap_total_kib`,
`swap_free_kib`, `balloon_kib`, `psi_some_total_us`, `psi_full_total_us`, `pgmajfault`,
`pswpin`, `pswpout`, `oom_kill`. Пустое значение означает, что источника нет (например, нет
файла давления или строки `Balloon` в `/proc/meminfo`).

`recordings_to_trace` сводит записи нескольких ВМ в одну трассу на общем отрезке времени с
линейным или удерживающим восстановлением между строками записи.

## Баллон

Если у баллона памяти включён `autodeflate`, гостевое ядро уже уменьшает `MemTotal` на размер
баллона. Передайте `autodeflate=True`, чтобы вычесть баллон ещё раз в `demand`; размер берётся
из столбца `balloon_kib` или из ряда `balloon_mib`. Без `autodeflate` баллон не вычитается.

## Часы

Столбец времени `t_real_s` сравним между машинами только после совмещения часов (см. функции
совмещения в API). `t_mono_s` годится только внутри одной машины.
