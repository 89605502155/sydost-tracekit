# Командная строка

У `sydost-tracekit` четыре команды. У каждой есть `--help`.

## record

Запускает гостевой регистратор на этой машине. Пишет CSV и JSON-сводку.

```sh
sydost-tracekit record --hz 10 --duration 600 --out trace_vm1.csv
```

## integrate

Оценивает дефицит по отсчётам эталонной трассы для нескольких шагов и методов. Файл выделения
имеет тот же формат и сетку, что и эталон.

```sh
sydost-tracekit integrate ref.csv --alloc alloc.csv --steps 0.5,1,2 --methods hold,linear
```

Вывод: точное `D` и относительная погрешность в процентах для каждого шага и метода.

## bound

Печатает константы эталонной трассы (`V`, `L`, `M`, `K`), линейную границу и границу удержания
`ℓ·V` для заданных шагов, а с `--target` — метод, шаг и частоту, при которых выполнена
абсолютная погрешность в МиБ·с.

```sh
sydost-tracekit bound ref.csv --steps 1,2 --target 10000
```

## tune

Повторяет фиксированные интервалы опроса на трассе, печатает стоимость (отсчёты на машино-час),
`P(θ)`, `D`, отметку фронта Парето и выбранный интервал при `P ≤ α` и `D ≤ D_max`.

```sh
sydost-tracekit tune train.csv --intervals 1,2,4,8 --theta 64 --alpha 0.5 --dmax 10
```

`--theta` — порог дефицита в МиБ. `--dmax` — в ГиБ·с. Без `--dmax` ограничения на `D` нет.
Если ни один интервал не удовлетворяет ограничениям, команда об этом сообщает.
